# 2026-08-27 工作日志

## Windows 助手（local_agent）前端窗口增加"解除配对并退出"按钮

背景：之前托盘模式的 `disconnect`（解除配对并退出）只在 `--background`（开机自启）模式下出现；双击桌面图标是窗口模式（`_run_status_window`），只有前端界面、无托盘菜单，因此窗口里无法解除配对。

改动（已完成，py_compile 通过）：
- `local_agent/theme.py`：新增 `danger_button()` 红色危险按钮样式（背景 STATUS_OFFLINE #b54835）。
- `local_agent/desktop.py`：
  - 新增模块级函数 `_revoke_pairing(application, store)`：通知服务器 `revoke_device`、本地 `store.clear()`、`set_autostart(False)`；网络失败忽略，与托盘行为一致。
  - `_run_tray` 内的 `disconnect` 改为复用 `_revoke_pairing`（行为不变）。
  - `_run_status_window` 增加 `store` 参数（此前只有 `connection`）；更新 3 处调用传入 `store`。
  - 窗口内新增"解除配对并退出"按钮：先 `messagebox.askyesno` 确认，再后台线程调用 `_revoke_pairing`，完成后 `application.stop()` + `root.destroy()` 退出窗口。

验证：仅改桌面 UI 与 theme，未触碰服务端；服务端 revoke 接口由 `tests/test_auth_multi_user.py` 等已有测试覆盖。
